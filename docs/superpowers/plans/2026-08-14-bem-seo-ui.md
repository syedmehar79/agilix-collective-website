# BEM + SEO + UI Bugfix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rename the site to consistent BEM classes, complete SEO/semantic HTML, and fix audited UI/quality bugs without changing the visual design.

**Architecture:** Block-by-block rename: update HTML, `css/style.css`, and JS selectors together per block so the site stays working after each task. Keep one stylesheet and relative paths. Finish with a site-wide SEO pass and regression smoke.

**Tech Stack:** Static HTML, `css/style.css`, vanilla JS, vendored jQuery/Owl. No package.json.

**Spec:** `docs/superpowers/specs/2026-08-14-bem-seo-ui-design.md`

## Global Constraints

- Visual look stays the same (colors, typography, spacing intent, layout, motion).
- Keep relative asset paths (`css/style.css`, `assets/...`, `js/...`).
- Keep a single site stylesheet: `css/style.css`.
- Keep vendored Owl / jQuery under `vendor/` (no npm).
- Do not rename image files on disk (e.g. `startegic.png` stays; improve `alt` only).
- Do not redesign, rewrite marketing copy for rankings, or replace carousels.
- Every renamed class used in `querySelector` / `classList` / generated HTML must be updated in the same change.
- BEM only: `block__element--modifier`. No `block__el__el`. Keep state classes (`is-open`, `is-active`, `is-in`, `is-menu-open`, …).
- Prefer `data-*` for JS-only hooks; keep existing `id`s needed for anchors/carousels.

And confirm no leftover old class in the files you touched (example for Task 1):

```bash
python -c "from pathlib import Path; bad=[]; 
for pat in ['primary-nav','nav-toggle','nav-logo','nav-left','nav-right','nav-mobile-panel']:
  for f in Path('.').rglob('*'):
    if f.suffix not in {'.html','.css','.js'} or 'node_modules' in f.parts or 'docs' in f.parts: continue
    t=f.read_text(encoding='utf-8', errors='ignore')
    if pat in t: bad.append(f'{f}:{pat}')
print('OK' if not bad else '\n'.join(bad)); raise SystemExit(1 if bad else 0)"
```

Adapt the `pat` list to the classes renamed in that task.
